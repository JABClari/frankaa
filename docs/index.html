frankaa

said FRAN-kah

Along the Fante coast of Ghana, each Asafo company has its frankaa: flags of bold appliqué, pictures cut from coloured cloth and sewn onto a field.

At festivals they are carried one after another in procession, then unfurled so the whole picture can be seen, while the drums keep time.

The parts are named after them: procession, the slider; unfurl, the lightbox; and drumline (dondo, the talking drum), the strip.

processionThe slider

A native scroll-snap track: the swipe is the browser's own, 1:1 with momentum. Photos past the first load as it comes near.

A card that opens the lightboxSwipe, scroll or use the arrow keys. Click a photo to open it.
import { procession, unfurl } from "frankaa";
import "frankaa/style.css";

const items = [{ src: "/a-800.jpg", full: "/a.jpg", alt: "Terrace" }, "/b.jpg", "/c.jpg"];
const slider = procession(card, items, {
  label: "Sea terrace",
  onSelect: (i) => unfurl(items, { start: i, origin: (n) => slider.image(n), onChange: (n) => slider.go(n, false) }),
});
"use client";
import { useRef } from "react";
import { Procession, useUnfurl } from "frankaa/react";
import "frankaa/style.css";

export function Card({ items }) {
  const slider = useRef(null);
  const lightbox = useUnfurl(items, { origin: (n) => slider.current?.image(n) ?? null, onChange: (n) => slider.current?.go(n, false) });
  return <Procession ref={slider} items={items} label="Sea terrace" onSelect={(i) => lightbox.open(i)} />;
}

unfurlThe lightbox

The photo lifts out of its spot and springs to full view. Swipe like a strip of film, pinch or double tap to zoom, pull down to close.

A grid that unfurls← → move, + - zoom, Esc closes.

drumline (dondo, the talking drum)The strip

A strip of pictures under a ruler of ticks. Drag or flick it, scroll either way, run along the ruler. The picture in focus grows; a tap opens it.

Preset Fluid WebGL 
import { drumline } from "frankaa";

drumline(el, items, { preset: "ruler" });                       // ticks, story cards, WebGL bend
drumline(el, items, { preset: "numbers", fluid: "lerp" });      // "28 [29] 30", tall bars
drumline(el, items, { preset: "minimal", colorFocus: true, onChange: (i) => {} });

togetherOne list, one option

Every part takes the same items. Each picks the file it needs: src for the slider, full for the lightbox, thumb for strips.
