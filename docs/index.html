Use it

plain TypeScript, no dependencies

Import the part you need. The React bindings are optional.

Built in

  • Native scroll snap: the swipe is 1:1 with the finger and keeps its momentum.
  • Photos past the first load only when the slider comes near the screen.
  • Two renderers: WebGL with shader effects, or CSS with transform and opacity only.
  • Keyboard, a focus trap, focus given back on close, and a polite live region.
  • Every string can be translated, and reduced motion is followed or overridden.
  • A photo WebGL cannot draw, or a shader that will not compile, falls back to CSS and fires onError.
  • No eval and no innerHTML: it runs under a strict Content Security Policy.
